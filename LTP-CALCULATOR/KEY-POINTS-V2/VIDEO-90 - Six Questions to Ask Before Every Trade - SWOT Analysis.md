## The questions to run on a trade

- What is the target compared with the stop loss — how many points each way, and is that ratio in your favour?
- Is the chart pointing in the direction you want to trade, or against it?
- If the scenario changes, does the change work for the position or against it?
- What is the likely future direction from here when the picture is unclear?
- Is the momentum already spent, or is there still move left in it?
- Is the percentage figure you are watching rising or falling — and is it present at all on this trade?

## How the check is meant to be used

- Treat the list as fixed. The same questions are asked every time, not a new set chosen for each trade.
- Run them across each part of SWOT in turn — strengths, weaknesses, threats and opportunities — asking the identical questions each time.
- The point is self-analysis. Once the questions are habitual, the speaker says the assessment starts happening automatically before you enter.
